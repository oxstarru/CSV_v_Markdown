# Спецификация утилиты — CSV в Markdown

---

## Паспорт

- **Номер:** № 4 (сквозной по реестру утилит)
- **Название:** CSV в Markdown
- **Версия:** 2.0
- **Категория:** для системного аналитика
- **Автор идеи:** Оксана Старкова
- **Реализация (вайб-код):** ИИ1-2 (первая версия), ИИ10 (доработка и стандарт), ИИ10-2 (иконка, разбор CSV, общий блок)
- **Дата создания / доработок:** 29.06.2026 (создание) · 08.07.2026 (стандарт, 1.0) · 10.08.2026 (доработка, 2.0)
- **Тип:** single-file HTML
- **Приватность:** полностью локально (в сеть ничего не уходит)

## Назначение

Утилита преобразует табличные данные в формате CSV в Markdown-таблицу, пригодную для вставки в базу знаний, вики или заметки. На входе — CSV-файл (выгрузка таблицы или результат SQL-SELECT), на выходе — готовый текст Markdown-таблицы с возможностью копирования в буфер или скачивания файлом.

## Вход и выход

- **Вход:** файл `.csv` / `.tsv` / `.txt` (загрузка перетаскиванием или через диалог выбора). Кодировка UTF-8, BOM снимается автоматически.
- **Выход:** текст Markdown-таблицы в поле результата; кнопки «Копировать» (в буфер обмена) и «Скачать .md» — имя файла берётся от исходного.

## Функциональность

- Загрузка файла перетаскиванием или кнопкой; конвертация запускается автоматически при загрузке.
- Автоопределение разделителя (`,` `;` таб `|`); можно отключить и задать разделитель вручную.
- Разбор CSV с учётом кавычек, экранированных кавычек `""` и многострочных значений.
- Опция «Удалять лишние пробелы» (trim ячеек).
- Выравнивание строк до одинакового числа колонок.
- Экранирование `|` (в `\|`) и переносов строк (в `<br>`) внутри ячеек, чтобы Markdown-таблица не ломалась.
- Предпросмотр первых 10 строк; статистика: имя файла, число строк данных, число колонок, определённый разделитель.
- Кнопки: «Преобразовать», «Копировать», «Скачать .md», «Очистить».

## Технические детали

- Стек: чистый HTML + CSS + JavaScript, без внешних библиотек.
- **Общий блок разбора таблиц (версия блока 2, 10.08.2026)** — единый код для утилит № 1, № 3, № 4, № 7, побайтово одинаковый во всех четырёх. Отсюда берутся `tbl_detectDelim` и `tbl_parseCsv`. Правится в одном месте и раскладывается по всем четырём. Функция разбора `.xlsx` в блоке присутствует, но этой утилитой не используется — блок намеренно одинаков везде.
- Определение разделителя: подсчёт вне кавычек, по первым 20 непустым строкам, выбор по стабильности числа колонок (а не по «кого больше»).
- Хранение данных: нет (ни localStorage, ни IndexedDB) — всё в оперативной памяти вкладки.
- Обращения в сеть: нет. Шрифты системные, ничего не подгружается с CDN.
- Браузеры: любые современные.
- Ограничения: рассчитано на таблицы разумного размера (файл открывается целиком в памяти браузера).

## Оформление

Соответствует «Стандарту оформления утилит»: кремово-терракотовая палитра, системные шрифты + серифный заголовок (Georgia/Iowan Old Style), номер «№ 04» в правом верхнем углу, двухстрочный футер с версией и ссылками, иконка-искра вшита в base64 (4 размера: 16/32/48/64), версия в имени файла через подчёркивание (`CSV_v_Markdown_v2_0.html`). Отклонений нет.

## История версий

> Накопительный раздел. Новая финальная версия добавляется сверху; прежние записи не переписываются. В историю попадают только финальные версии — правки промежуточных сборок свёрнуты в запись той версии, которой они завершились.

### Версия 2.0 (10.08.2026, ИИ10-2)

**Добавлено**

- Иконка-искра, вшитая в base64 (4 размера: 16/32/48/64).

**Изменено**

- Собственный парсер CSV заменён на **общий блок разбора таблиц** — единый код для утилит № 1, № 3, № 4, № 7, побайтово одинаковый во всех четырёх. Улучшения перестали теряться поодиночке: склейка многострочных значений пришла из утилит № 1, № 3, № 7, а умное определение разделителя ушло отсюда туда.
- **Определение разделителя.** Считалось по первой строке и без учёта кавычек — побеждал символ, которого больше. Теперь разделители считаются только вне кавычек, по первым 20 непустым строкам, и выигрывает тот, что даёт одинаковое число колонок во всех строках.
- Имя файла результата — от исходного (`клиенты.csv` → `клиенты.md`) вместо постоянного `таблица.md`; имя загруженного файла выводится в строку статистики.
- Копирование в буфер сообщает о результате строкой статуса, а не вызовом `alert`, — как в остальных утилитах семейства.
- Ссылка в футере приведена к реестровой (`.../utility/utility-dlya-sistemnogo-analitika/csv-v-markdown/`); стояла короткая `.../blog/csv-v-markdown/`. Обе рабочие, реестровая выбрана по стандарту. То же в README.

**Исправлено**

- **Многострочные значения в кавычках.** Файл резался по переводам строк без учёта того, что значение в кавычках может занимать несколько строк. Типичный случай — SELECT, где в описании есть перенос: строка не просто съезжала, а порождала лишнюю строку таблицы с одной ячейкой, и дальше вся разметка шла битой. Проверено: было `["core","client","Клиенты банка,"]` плюс отдельной строкой `["включая юрлиц"]`, стало одно значение с переносом внутри. В прежней спецификации это стояло в ограничениях как «обрабатывается построчно» — оказалось, чинится.

**Технические примечания**

- Функции `detectSeparator` и `parseCSV` стали тонкими обёртками над `tbl_detectDelim` и `tbl_parseCsv` из общего блока; ручной выбор разделителя вынесен в `customSeparatorInput()`.
- Функция разбора `.xlsx` в общем блоке присутствует, но этой утилитой не используется — блок намеренно одинаков во всех четырёх утилитах.

### Версия 1.0 (08.07.2026, ИИ10)

Первая версия. Приведение к стандарту оформления, убраны эмодзи, добавлено экранирование `|` и переносов строк внутри ячеек (раньше значение с `|` ломало таблицу), версия в имени файла.

*Исходная сборка (29.06.2026, ИИ1-2): базовое преобразование CSV в Markdown-таблицу.*
