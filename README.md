# CSV_v_Markdown

Маленькая утилита, которая превращает CSV-файл (обычную таблицу или результат SELECT из базы) в аккуратную Markdown-таблицу — чтобы её можно было сразу вставить в базу знаний, вики или заметки. Загружаешь файл — получаешь готовую таблицу, которую можно скопировать одной кнопкой или скачать файлом. Работает прямо в браузере, ничего устанавливать не нужно.

## Как работает

- **Где работает:** любой современный браузер (Chrome, Edge, Firefox, Safari). Ничего не устанавливается — просто открой файл.
- **Что делать:** перетащи CSV в окно (или нажми «Выбрать файл») — таблица преобразуется сразу. Дальше «Копировать» или «Скачать .md». Имя скачанного файла берётся от исходного: `клиенты.csv` → `клиенты.md`.
- **Разделитель** утилита определяет сама — запятая, точка с запятой, табуляция, вертикальная черта. Считает их только вне кавычек и выбирает тот, что даёт одинаковое число колонок во всех строках, поэтому запятые внутри текста её не сбивают. Если всё же нужно задать вручную — отключи «Автоопределение разделителя».

## Нюансы

Значения, где встречается символ `|` или перенос строки, экранируются автоматически, чтобы таблица не ломалась. Многострочные значения в кавычках (когда в ячейке несколько абзацев) читаются правильно — строка не разваливается. Кодировка — UTF-8, BOM снимается сам.

## Приватность

Данные хранятся только на вашем компьютере, в интернет ничего не уходит. Файл читается прямо в браузере, никуда не отправляется; внешних библиотек и шрифтов из сети утилита не подгружает.
